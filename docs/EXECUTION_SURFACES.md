# Execution Surfaces

DACP execution surfaces are adapters, not authorities.

- Claude (claude.ai / Claude Code) and ChatGPT: authorized executors, one at a time as Gene chooses; reasoning, orchestration and authorized connected actions. Shared state: projects/skyhawk/LOST-D.md.
- GitHub/Git: durable public specification state and version history.
- Terminal/SSH: local or remote command execution when the task requires it.
- Mac/Windows/Pixel: replaceable clients that expose whichever execution surface is appropriate.

The execution surface may change without changing the endpoint, evidence requirements, authority, verification, privacy boundaries, or the H-017 role allocation.
