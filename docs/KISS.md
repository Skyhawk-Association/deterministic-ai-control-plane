# KISS / Anti-Ceremony Principle

DACP controls must justify their burden. Low-risk reversible work should remain easy; consequence drives control depth.

The system should not make Gene perform mechanical work that an authorized competent AI execution path can safely perform. Nor may convenience be used to waive material safety, privacy, authority, evidence, or verification requirements.
