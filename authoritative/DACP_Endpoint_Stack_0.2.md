# DACP Endpoint Stack 0.2

**Status:** AUTHORITATIVE PROJECT DECISION
**Effective:** Immediately, until explicitly superseded
**Supersedes:** DACP Endpoint Stack 0.1
**Source:** Gene's current instruction of 2026-09-06
**Scope:** Deterministic AI Control Plane project direction

## Immediate endpoint

Use Heuristics Specification 0.1 as the current universal control hypothesis in real work. Attack it through use at every material gate where the challenge can affect correctness. Correct demonstrated defects immediately through the versioned standing-correction process, preserving evidence and prior state. Do not return to speculative rewrite loops unless field evidence exposes a specification-level problem.

## Intermediate endpoint

Gather broad operational evidence while keeping the heuristic set under continuous survival pressure. Measure whether the rules actually improve correctness, trust, cost, latency, privacy, recovery, user friction, and completion. Merge, narrow, rewrite, suspend, or retire rules that fail. Add a new control only when causal diagnosis shows that the existing set cannot express the required protection simply.

The active heuristic count is not a target. The smallest complete set that survives evidence is the target.

## Long-term endpoint

Build the Deterministic AI Control Plane application after field use has produced enough provider/tool contracts, telemetry requirements, privacy behavior, failure evidence, and measurable acceptance criteria to justify implementation.

## Existential endpoint

Make AI useful, likeable, and practical enough to become an everyday tool for everyone.

This endpoint is continuously applicable. It does not override safety, privacy, evidence, or authority, but it requires every control to justify the burden it imposes on ordinary use. Correctness that humans reasonably refuse to use is not the complete endpoint.

## Endpoint relationship

Higher endpoints constrain the immediate endpoint, but execution should operate primarily against the properly formed immediate endpoint. Reopen the stack only when new evidence, changed authority, changed constraints, changed endpoints, or observed mismatch materially requires it.
