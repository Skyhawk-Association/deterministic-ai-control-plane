# DACP Governance Supersession Notice 0.2

**Status:** AUTHORITATIVE within the scope stated below
**Effective:** Immediately, until explicitly superseded
**Supersedes:** DACP Governance Supersession Notice 0.1
**Purpose:** Remove ambiguity from stale smoke-test language without making unsupported historical claims about the present contents of older artifacts.

## Governing source

`Project Instructions 0.2` governs the current deterministic project smoke test.

The valid smoke-test command is:

`DACP_CHECK_01`

The required response is:

`DACP 0.1 ACTIVE | Candidate capture: ON | Silent promotion: BLOCKED | Review: Philip / Jennie / Jake / Gene`

## Superseded behavior

`H01CHECK` is retired and must not be interpreted as the Project smoke-test command.

Any occurrence of `H01CHECK` in any older project artifact, copied instruction, historical chat, export, handoff, or other preserved source is stale on that point and is superseded by `Project Instructions 0.2`.

This notice does **not** assert that any particular older file still contains `H01CHECK` in its current retrievable contents. Historical and current file contents must be established from the file or revision being examined.

## Scope

This notice does **not** silently rewrite, repeal, or promote any other provision in older artifacts.

Where an older artifact conflicts with `Project Instructions 0.2`, the current instructions govern within the conflicting scope.

Where no conflict exists, the older artifact retains only whatever status it otherwise has.

## Preservation rule

Older files are preserved as historical/project evidence until deliberately reclassified, superseded, or replaced. They are not deleted merely because one provision became stale.
